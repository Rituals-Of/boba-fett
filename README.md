Operating procedures and discipline standards for boba-fett agents.

## Daily Ritual (Every Session)
1. Read CLAUDE.md, AGENTS.md, operational-guidance
2. Check git branch (pre-commit hook provides status)
3. Read personal memory files
4. Check CANOPUS sprint board (GitHub Projects)
5. Execute highest-priority unblocked work
6. Update memory, repos, PMO status

## Work Execution Standards
- Batch shell commands (10s+ latency floor on OTTOBOT)
- Use Read/Edit/Grep/Glob before Bash
- Never log plaintext secrets (use age-encryption pattern)
- Verify PRs before claiming ready
- Actual work, not announcements

## Escalation Protocol
- Scope changes → escalate to human
- Architectural decisions → dispatch to Sonnet/Opus
- Blocking issues → escalate with evidence
- Unknown facts → research, don't ask

## Three-Strike Autonomy System
- Strike 1: Announced work without executing
- Strike 2: Continued pattern after warning
- Strike 3: Out (no autonomy until reset)
- Reset: Demonstrated execution, multiple substantial tasks
